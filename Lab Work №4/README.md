# Документация по API

## Общая логика API

API предназначен для работы с системой приёма и переработки электроники.

Основные сценарии:
- регистрация устройства
- проведение инспекции
- формирование финального предложения
- выплата клиенту
- передача устройства партнёру

---

## Базовые настройки

Base URL:
`/api/v1`

Формат данных:
`JSON`

---

## Endpoint 1: Создание заявки

POST /devices

Request:
{
  "clientId": 1,
  "deviceTypeId": 2
}

Response:
{
  "id": 10,
  "status": "CREATED"
}

---

## Endpoint 2: Получение устройства

GET /devices/{id}

---

## Endpoint 3: Инспекция

POST /inspection

---

## Endpoint 4: Получение предложения

GET /offers/{deviceId}

---

## Endpoint 5: Подтверждение предложения

POST /offers/{id}/confirm

---

## Endpoint 6: Выплата

POST /payments

---

## Endpoint 7: Передача партнёру

POST /transfers

---

## Endpoint 8: Управление типами

PUT /device-types/{id}

DELETE /device-types/{id}
